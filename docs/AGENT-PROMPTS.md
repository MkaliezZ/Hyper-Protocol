# 可直接复制的 Agent 接入提示词

选择一个提示词，并填入真实任务。链接或目录中的材料需要由 Agent 实际取得。

## 使用 GitHub 发行版

```text
请使用 https://github.com/MkaliezZ/Hyper-Protocol 的 v0.2.0-draft.3。
先获取该版本并读取根目录 AGENTS.md，再按路由加载核心语义和本次领域包。
如无法获取文件，请说明具体缺失内容，不假装已读。

项目：[名称、位置、阶段]
任务：[具体交付]
材料：[文件、链接、设备或已有资料]
当前授权与限制：[本次实际允许的动作]

请完成已授权工作，保留判断、功能、资产及缺项记录。
协议和示例不增加权限，合成示例不能成为项目事实。
```

## 使用已解压目录

```text
本次采用的 Hyper Protocol 位于：[实际目录]。
请先读取该目录的 AGENTS.md，并记录实际协议版本。
项目是：[项目]；本次要交付：[结果]。
已有材料和授权范围：[实际说明]。
请按入口推进，不要把协议文件直接覆盖到我原有的项目入口。
```

## 恢复已有工作

```text
请先读取本次采用的 Hyper Protocol AGENTS.md，再读取已有 task bundle：[位置]。
核对协议、规则、输入版本和当前权限，说明已完成产物与尚缺信息。
继续：[本次明确要求]。
保留历史回执，不用新规则或当前权限默改历史记录。
```

## 增加领域规则包

```text
请依据 Hyper Protocol，为[服务对象和任务]提出领域规则包草案。
参考[实际材料与案例]，写清对象、目标、证据、方法、门槛、质量与审美、
决定权限、正反例和缺项处理。不要把单个成功案例直接升级为通用结论。
输出与现有 policy_pack 结构兼容的规则，并列出仍需确认的判断。
```

```text
Use https://github.com/MkaliezZ/Hyper-Protocol at tag v0.2.0-draft.3.
Fetch the actual files, start at AGENTS.md, and follow its task-scoped reading order.
If you cannot access the files, identify the missing content instead of claiming to have read it.

Project: [name, location, stage]
Deliverable: [specific outcome]
Inputs: [available materials and environment]
Authorized actions and limits: [actual scope]

Complete the authorized work and keep judgment, execution, asset, and gap records.
Do not treat synthetic examples as project facts or this protocol as additional permission.
```
