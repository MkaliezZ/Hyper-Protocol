# Hyper Protocol v0.2.0-draft.1

面向 Agent 的判断层、功能层、资产层协作协议，首次公开发行。

解压附件中的 Agent ZIP，将整个目录交给 Agent，并要求先读根目录 `AGENTS.md`。仓库 README 和 `docs/GETTING-STARTED.md` 提供可直接复制的接入提示词、按能力接入、任务记录、校验和恢复步骤。

包含三层定义、固定状态、六类记录、12 个领域规则包草案、JSON Schema、任务模板、13 个合成正反例、可选校验器和来源说明。

规范与文档采用 CC BY 4.0；代码、Schema 和 JSON 模板及样例采用 Apache-2.0，范围见 `LICENSE-NOTE.md`。

协议版本保持 `0.2-draft`。本次检查覆盖结构、规则记录一致性、独立 Python 环境、发行包完整性和解压后运行；不代表独立 Agent、跨模型或真实领域效果已验收。
